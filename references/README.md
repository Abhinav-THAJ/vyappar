## Usage rules

These are **layout and workflow** references only. Per the brief we replicate structure,
information architecture and flows — never Vyapar's name, logo, icons, illustrations,
colour palette or any image asset. All screenshots stay out of the shipped bundle;
nothing in `references/` is imported by application code.
